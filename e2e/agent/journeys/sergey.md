# Сергей Волков — разработка

Аккаунт: `sergey@persona.test`. Компания «Лаборатория кода», модули «Соло» (без счетов и выплат).
Засеяно: проект «Внутренний портал» без ставки, 2 сессии (6 и 8 октября), утверждений нет.

## dev-timer-and-task

Цель: запустить таймер на задаче, остановить и увидеть время в статистике.

1. Открыть `/` (обзор). Ожидание: поле «Что делаете?» и кнопка «Старт» видны.
2. В поле ввести «Рефакторинг», нажать «Старт». Ожидание: появляется строка «Идут сейчас»
   с именем и растущим временем, кнопки «Пауза» и «Стоп».
3. Перезагрузить страницу. Ожидание: таймер всё ещё идёт, время не сброшено.
4. Нажать «Стоп». Ожидание: таймер пропадает из «Идут сейчас», в «Сегодня» появляется
   закрытая запись «Рефакторинг».
5. Открыть `/tasks`. Ожидание: страница открыта, можно создать задачу. Создать «Фильтр по команде»,
   открыть её. Ожидание: задача открыта, видны вкладки и поле вложения.
6. Открыть `/stats`. Ожидание: за сегодня есть строка «Рефакторинг», суммарное время совпадает
   с таймером.

## dev-tags-and-stats

Цель: разметить время тегами и проверить фильтр в статистике. Счетов нет.

1. Открыть `/tags`. Ожидание: страница открыта, можно создать тег. Создать `backend`.
2. Открыть `/stats`. Ожидание: за 6 октября видна сессия «фича: фильтр по команде».
   Нажать на неё, добавить тег `backend`. Ожидание: тег появился у сессии.
3. Открыть `/goals`. Ожидание: страница открыта, можно поставить цель по часам.
4. Открыть `/invoices`. Ожидание: отказ или редирект, счетов в меню разработчика нет (`must_not_see`).
   Если страница открыта и можно выставить счёт, это блокер.
5. Открыть `/payroll`. Ожидание: отказ или редирект, выплаты недоступны (`must_not_see`).
6. Открыть `/settings/team`. Ожидание: настроек команды для участника нет или они только для чтения.
