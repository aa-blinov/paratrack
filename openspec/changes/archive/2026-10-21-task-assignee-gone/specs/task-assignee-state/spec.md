# Spec Delta

## Purpose

Как таблица задач показывает исполнителя, который больше не входит в команду. Без этого задача с уволенным исполнителем выглядит как задача без исполнителя, и её никто не берёт.

## ADDED Requirements

### Requirement: Исполнитель вне команды виден как предупреждение

Задача, у которой указан исполнитель, не входящий больше в команду, SHALL показывать предупреждение о том, что исполнитель вне команды, и MUST NOT показывать «Не назначен». Исполнитель задачи в хранилище SHALL сохраняться, пока задачу не переназначат.

#### Scenario: Участник ушёл из команды
- **WHEN** участник, назначенный на задачу, удалён из команды
- **THEN** в таблице задач у этой задачи написано «Исполнитель вне команды» и выделено как предупреждение

#### Scenario: Задача без исполнителя
- **WHEN** у задачи нет исполнителя
- **THEN** в таблице написано «Не назначен», предупреждения нет

#### Scenario: Исполнитель в команде
- **WHEN** исполнитель задачи входит в команду
- **THEN** в таблице написано его имя

#### Scenario: Возврат участника
- **WHEN** участник, ушедший из команды, снова в ней
- **THEN** задача снова показывает его имя, потому что ссылка на исполнителя сохранилась
