# Proposal

## Why

На странице проекта план показан дважды. Карточка «Спланировано за всё время» выводит сумму расписания по проекту, а таблица «По людям» выводит план каждого человека за тот же период. Сумма карточки уже есть в таблице, поэтому руководитель видит одну цифру два раза (PLAN-03, P1).

Проверено в коде. `internal/web/project_plan.go`: `PlannedLabel` суммирует `planned[member]` по участникам, а `planned` берётся из `PlannedMinutesForProject` за все дни. Таблица «По людям» использует те же `planned`. Остаток по смете (`RemainingLabel`) считается по другому окну: план только с сегодняшнего дня (`PlannedAhead`), это описано подсказкой `proj.remainingHint`. Карточку «Спланировано» в тестах и e2e никто не проверяет.

## What Changes

- Карточка «Спланировано за всё время» убирается со страницы проекта.
- В конец таблицы «По людям» добавляется строка «Итого за всё время» с суммой плана и, для руководителя, суммой учтённого времени. Сумма строки равна сумме колонки, поэтому цифра одна и на одном месте.
- Период «за всё время» назван прямо, в подписи итога. Остаток по смете остаётся с окном «от сегодня» и своей подсказкой: два окна разделены явно, не скрыты.
- Словарь: ключ `proj.totalAllTime` в `ru.json` и `en.json`.

## Capabilities

### New Capabilities
- `project-plan-view`: страница проекта показывает план по проекту один раз, с периодом и итогом, который равен сумме по людям.

### Modified Capabilities
Нет. В `openspec/specs/` спецификаций страницы проекта нет.

## Impact

- Go: `internal/web/project_plan.go` (поле итога учтённого времени `TrackedLabel` в `projectPlanView`), `internal/web/handlers_projects_pages.go` (передача поля в данные страницы), `internal/web/view_projects.go` (поле `TrackedLabel` в данных).
- Web: `web/src/projects/project-detail.tsx` (убрать `SummaryCard` с `proj.plannedAll`, строка итога в таблице), `web/src/dashboard/types.ts` (поле `TrackedLabel`).
- i18n: `proj.totalAllTime` в ru и en.
- Тесты: Go на сумму строк и итог (с учтённым временем для руководителя и без него), web-тест страницы проекта (одна сумма плана, строка итога), e2e на холодном стенде.
- Бандл `internal/web/static/ui` пересобирается и коммитится.
- Совместимость: внешних потребителей страницы нет, API проекта не меняется.
- Вне scope: планы по неделям (PLAN-02), остаток по смете и его окно, загрузка команды (PLAN-01 уже закрыт), другие пункты PLAN-, TIME-, ADM-, FIN-.
