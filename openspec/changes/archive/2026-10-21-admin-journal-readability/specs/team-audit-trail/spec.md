# Spec Delta

## Purpose

Журнал должен читаться без расшифровки кодов: кто сделал, с кем и что изменилось. Строка показывает исполнителя по имени, цель и деталь на языке интерфейса, а фильтр «Кто» находит и тех, кто уже покинул пространство. Записи журнала при этом не меняются: отображение считается при чтении.

## ADDED Requirements

### Requirement: Строка журнала называет исполнителя по имени

Каждая строка журнала SHALL показывать имя исполнителя, а если имени нет, его адрес. Имя берётся из учётной записи, поэтому бывший участник остаётся именованным. Исполнитель MUST NOT показываться числовым id.

#### Scenario: Бывший участник изменил роль
- **WHEN** участник, который уже покинул пространство, оставил строку в журнале
- **THEN** в строке стоит его имя, а не id

#### Scenario: Имени нет
- **WHEN** у учётной записи пустое имя
- **THEN** в строке стоит адрес, как в списке участников

### Requirement: Цель и деталь строки читаются по-человечески

Строка журнала SHALL показывать цель и деталь на языке интерфейса, без служебных кодов вида `user:<id>` или `invoice:<id>`. Деталь выводится только там, где она несёт смысл для читающего.

#### Scenario: Смена роли
- **WHEN** владелец сделал участника Марию администратором
- **THEN** строка «Изменена роль» показывает цель «Мария» и деталь «администратор» (на языке интерфейса)

#### Scenario: Отзыв токена
- **WHEN** пользователь отозвал токен «sync-laptop»
- **THEN** строка «Отозван API-токен» показывает деталь «sync-laptop»

#### Scenario: Удаление участника
- **WHEN** владелец удалил участника Ивана Петрова
- **THEN** строка «Участник удалён» показывает цель «Иван Петров» и не показывает служебный `user:<id>`

#### Scenario: Удаление счёта
- **WHEN** руководитель удалил черновик INV-2026-001
- **THEN** строка «Счёт удалён» показывает цель INV-2026-001 и не показывает `invoice:<id>`

#### Scenario: Восстановление пространства
- **WHEN** пространство восстановлено из файла под названием «Студия»
- **THEN** строка «Пространство восстановлено из файла» показывает цель «Студия», а не `team:<id>`

### Requirement: Фильтр «Кто» включает бывших участников

Фильтр «Кто» SHALL предлагать каждого, кто оставил хотя бы одну строку журнала пространства, включая тех, кто уже не состоит в команде. Выбор такого человека MUST сужать список строк.

#### Scenario: Выбор бывшего участника
- **WHEN** руководитель выбирает в фильтре «Кто» бывшего участника
- **THEN** список показывает только строки, оставленные им, а не весь журнал

#### Scenario: Пустой выбор
- **WHEN** в журнале нет строк ни одного бывшего участника
- **THEN** в фильтре только текущие участники, как прежде
