## О чём эти условия

paratrack — сервис учёта времени. Есть общедоступная версия на [paratrack.duckdns.org](https://paratrack.duckdns.org) и возможность поставить тот же код на свой сервер. Эти условия касаются общедоступной версии; свой сервер вы обслуживаете сами, код распространяется по лицензии [MIT](https://github.com/aa-blinov/paratrack/blob/master/LICENSE).

## Аккаунт

1. Аккаунт создаётся по адресу почты и паролю. Пароль от 8 символов, хранится только в виде bcrypt-хеша.
2. Один человек может держать несколько пространств; в одном пространстве — несколько людей с ролями. Владелец пространства управляет участниками.
3. Смена пароля закрывает все сессии, кроме той, из которой её сделали. Ссылка восстановления живёт 30 минут и срабатывает один раз.
4. Удалить пространство может только его владелец и только если он в нём один. Удаление стирает данные без восстановления: [дней на отмену нет / есть период отмены].

## Ваши данные

1. Учтённое время, проекты, клиенты, счета и выплаты принадлежат вам. Сервис обрабатывает их, чтобы показать их вам, и не использует их для чего-либо ещё.
2. Выгрузка целиком: в пространстве есть экспорт в файл и восстановление из него. Мы не держим ваши данные заложниками: уйти можно со всем.
3. Резервные копии общедоступной версии делаются [раз в сутки]; хранятся [30 дней]. Восстановление по запросу: [срок ответа].
4. Мы читаем содержимое ваших данных только по вашей явной просьбе, для поддержки. Автоматические отчёты об ошибках (Sentry) содержат адреса страниц и стек вызова, но не содержимое полей и не пароли.

## Что сервис обещает

1. Приложение доступно по адресу [paratrack.duckdns.org] с целью [99.x% времени в месяц]. Статус: [страница статуса / адрес]. О поломках, длящихся больше [часа], сообщаем: [куда].
2. Обновления выхода из строя не ломают: перед выкладкой прогоняется полный набор проверок, включая браузерные.
3. Поддержка: [канал], ответ за [рабочих часов]. Реакция на инциденты безопасности: [часов], с раскрытием деталей после закрытия.

## Чего не делать

1. Не пытаться получить доступ к чужим пространствам, не перебирать пароли и токены. Лимиты на попытки входа стоят и уже задокументированы.
2. Не использовать сервис для учёта времени, который вы не имеете права учитывать: чужие таймеры, конфиденциальные названия задач под NDA — ваше ответственность перед третьими лицами, не наша.
3. Нарушения: сначала предупреждение, при повторе — закрытие аккаунта с правом выгрузки данных.
