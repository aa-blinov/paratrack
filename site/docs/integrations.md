## Задачи из трекеров

Подключите трекер задач, и его открытые задачи появятся в paratrack. У каждой задачи есть кнопка «Старт»: таймер запустится с названием задачи, без перепечатывания.

«Ещё» → «Интеграции» → «Подключить источник», или «Маркетплейс интеграций», где видно, что работает, а что скоро.

| Сервис | Ключ доступа | Откуда брать задачи |
|---|---|---|
| **GitHub** | Personal access token (GitHub → Settings → Developer settings), доступ `repo` | `владелец/репозиторий`; пусто: задачи, назначенные на вас |
| **GitLab** | Personal access token (Preferences → Access tokens), доступ `read_api` | `группа/проект`; для своего GitLab адрес первым: `https://git.company.ru группа/проект` |
| **Jira** | `почта:api-токен` для Jira Cloud (токен из id.atlassian.com) или PAT для Data Center | адрес сайта и ключ проекта или JQL: `https://acme.atlassian.net PROJ` |
| **Trello** | `key:token` из trello.com/power-ups/admin | id доски: часть ссылки после `/b/` |
| **Asana** | Personal access token (My settings → Apps → Developer apps) | GID проекта: число из ссылки |
| **ClickUp** | API-токен `pk_…` (Settings → Apps) | id списка: число из ссылки |
| **Todoist** | API-токен (Настройки → Интеграции → Разработчику) | id проекта, можно не заполнять |
| **Notion** | секрет внутренней интеграции `ntn_…` (notion.so/my-integrations) | id базы: 32 символа из ссылки. Базу нужно открыть этой интеграции |

После подключения нажмите «Синхронизировать»: paratrack загрузит задачи со всех страниц выдачи сервиса. Повторная синхронизация обновляет список, дублей не бывает.

Ключи доступа хранятся на сервере в зашифрованном виде. Подключать и удалять интеграции могут владелец и администраторы, запускать таймеры по задачам могут все.

## Перенос истории

«Ещё» → «Импорт»: перенесите прошлые записи из другого трекера. Они станут обычными сессиями paratrack.

| Откуда | Что нужно |
|---|---|
| **Toggl** | API-токен (Toggl → Profile settings, внизу страницы) |
| **Harvest** | Personal access token (id.getharvest.com/developers) и id аккаунта, он показан рядом с токеном |
| **Clockify** | API-ключ (Profile settings → API); id рабочего пространства можно не указывать, возьмём активное |

1. Выберите источник, вставьте ключ, укажите период.
2. Нажмите «Предпросмотр» и проверьте, что именно перенесётся.
3. Нажмите «Импортировать».

- Переносятся только завершённые записи, идущие таймеры пропускаются.
- Повторный импорт того же периода не создаёт дублей: paratrack помнит, какие записи уже перенесены.
- Toggl отдаёт записи только за последние 3 месяца, это ограничение самого Toggl.
