Time tracking that turns into an invoice.

Several timers run at once, the week lands in a timesheet, and the same minutes become a client invoice or a team payout. paratrack works in the browser and on a phone, and one docker compose puts it on your own server.

Open paratrack

MIT licence. The interface is Russian, and English is there too. Light and dark themes.

The same minutes reach the invoice

The timers write straight into the timesheet and into the invoice draft for Romashka. The hours are rounded to hundredths of an hour (36 seconds), and every line reads hours × rate = amount. The total of the invoice matches the timesheet to the kopeck, so there is nothing to recalculate by hand.

The data can live with you

Use the service, or put the same application on your own server: one application and Postgres in docker compose. The schema of the database is created and migrated at startup.

git clone https://github.com/aa-blinov/paratrack
cd paratrack
cp .env.example .env
# in .env: POSTGRES_PASSWORD and PARATRACK_SECRET_KEY
docker compose up -d --build
# -> http://127.0.0.1:8000/register

  • Integrations and import

    Tasks from GitHub, GitLab, Jira, Trello, Asana, ClickUp, Todoist and Notion. History imported from Toggl, Harvest and Clockify.

  • API, webhooks, log

    Read-only tokens, a REST API with pagination, signed webhooks, an audit log and OIDC single sign-on.

  • Terminal and browser

    A CLI for start, stop and stats, and a Chrome extension that keeps a timer in the popup.

The details, with the environment variables, the backups and the updates: your own server.
