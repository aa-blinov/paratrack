Учёт времени, из которого сразу выходит счёт

Запускаете таймеры на задачах, хоть три сразу. paratrack раскладывает минуты по проектам и дням, собирает табель, счёт клиенту и выплаты команде. Работает в браузере и на телефоне, ставится на свой сервер.

Открыть paratrack Развернуть у себя

Интерфейс на русском, есть английский. Исходный код открыт, лицензия MIT.

Те же минуты доходят до счёта

Таймер выше пишет прямо в табель и в черновик счёта для «Ромашки». Часы округляются до сотых (36 секунд), и в каждой строке «часы × ставка = сумма». Итог счёта сходится с табелем до копейки, пересчитывать в таблице не придётся.

Один человек, фрилансер или студия

При регистрации выбираете, как будете работать, и в меню остаётся только нужное. Обзор, статистика, табель и проекты есть всегда, остальное включается позже в пару нажатий.

Данные могут жить у вас

Пользуйтесь сервисом или поднимите такой же на своём сервере: одно приложение и Postgres в docker compose. Схема базы создаётся и обновляется сама.

  • Интеграции и импорт

    Задачи из GitHub, GitLab, Jira, Trello, Asana, ClickUp, Todoist и Notion. История из Toggl, Harvest и Clockify.

  • API, вебхуки, журнал

    Токены с правами «только чтение», REST API, подписанные вебхуки, журнал действий.

  • Терминал и браузер

    CLI для start, stop, stats, расширение для Chrome с таймером в попапе.

$ git clone https://github.com/aa-blinov/paratrack
$ cd paratrack && cp .env.example .env
# в .env: POSTGRES_PASSWORD и PARATRACK_SECRET_KEY
$ docker compose up -d --build
# → http://127.0.0.1:8000/register

Подробно, с переменными окружения, бэкапами и обновлением: свой сервер.

Первый таймер за минуту

Регистрация по почте. Сразу после неё paratrack спросит, как вы будете работать, и откроет обзор с полем «Что вы делаете?».
