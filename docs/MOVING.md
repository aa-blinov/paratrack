# Переезд: выгрузить пространство и открыть его в другом месте

Пространство можно выгрузить целиком одним файлом и открыть в другой установке
paratrack или перенести данные куда-то ещё. Файл читаемый: это JSON, у каждого
раздела есть имя, а значения времени записаны так, как их хранит база.

## Выгрузить

Владелец или администратор: **Экспорт → Всё пространство → Скачать JSON**.
Участник выгрузку не получает: в файле ставки и счета всех людей.

Файл называется `paratrack-<пространство>-<дата>.json`. В нём есть поле `version`:
сейчас это `1`. Читатель принимает только свою версию и говорит, почему отказал.

## Что в файле

| Раздел | Что внутри |
|---|---|
| `team` | название, валюта, округление времени, префикс номеров счетов, реквизиты, НДС, логотип, набор разделов |
| `members` | люди по email, роль, почасовая ставка, ёмкость дня, административные минуты |
| `clients`, `projects` | клиенты; проекты со ставкой, billable, валютой, бюджетом, оценкой, сроком и руководителем |
| `activities`, `tags` | активности (с проектом и задачей) и теги |
| `sessions` | все завершённые сессии: кто, какая активность, начало, конец, заметка, теги, счёт |
| `goals` | цели по активностям |
| `tasks` | доска: статус, исполнитель, срок, оценка, ссылка на GitHub, если задача перенесена оттуда |
| `invoices` | счета с номером, клиентом, статусом, квитанцией и строками |
| `payroll_runs` | расчётные листки со строками по людям |
| `schedule_entries`, `schedule_lines` | план по людям и дням |
| `timesheet_approvals` | подтверждённые недели |
| `saved_reports` | сохранённые отчёты |

## Чего в файле нет

- Пароли, сессии входа, API-токены и push-ключи.
- Ключи Stripe и секреты вебхуков.
- Интеграции: при восстановлении их подключают заново.
- Идущие и приостановленные таймеры: это незавершённая работа. Остановите их до выгрузки.
- Ссылки на оплату счетов и номера платёжных сессий: они принадлежат платёжному сервису.

## Открыть в другом месте

1. Каждый человек из файла должен быть зарегистрирован там же, под тем же email.
   Без этого восстановление отказывает и называет, кого не хватает. Пароли в файле
   не хранятся, поэтому создать аккаунт за человека нельзя.
2. Войдите и откройте **Импорт → Восстановить пространство из файла**, выберите
   файл, нажмите «Восстановить».
3. Пространство создаётся заново: вы его владелец, остальные получают свои роли.
   Прежний владелец из файла становится администратором: у пространства один владелец.
   Пространство становится текущим.
4. Скопируйте секреты вебхуков с экрана восстановления. Файл их не содержит,
   поэтому каждому вебхуку дан новый секрет, и он показан один раз. Поставьте его
   в принимающей системе. Старые вебхуки в прежнем пространстве продолжают
   отправлять, пока вы их не удалите там.
5. Проверьте проекты, ставки, счета. Заново подключите интеграции и платёжные
   ключи, если они нужны.

Восстановление ничего не пишет, пока не сверит всех людей из файла: при отказе
пространство не создаётся. Файл может весить до 1 ГБ.

## Забрать данные через API

Для переезда кодом токен только для чтения (**Настройки → API-токены**, галочка
«Только чтение») открывает:

- `GET /api/v1/projects`, `/api/v1/clients`, `/api/v1/tags`, `/api/v1/tasks`
- `GET /api/v1/sessions` с курсором, `GET /api/v1/reports/summary`

## Ограничения

- Выгрузка и восстановление идут потоком, запись за записью, поэтому большое
  пространство не держится в памяти целиком. Файл больше 1 ГБ сервер не принимает.
- Файл, скачанный не до конца, восстановление отвергает: пространство не создаётся.
- Импорт из Toggl, Harvest и Clockify — отдельный путь: он переносит записи
  времени, а не пространство целиком.
