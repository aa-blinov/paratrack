# User Journey Map — paratrack

Актуальная карта переходов по состоянию продукта (волны 1–9). Каждый маршрут
проверен в UI; отмечено, где пользователь попадает и что помогает ему не
заблудиться.

---

## 0. Ландшафт: где что живёт

```
Верхняя панель (одна строка, никогда не переносится)
├─ paratrack          → /                       логотип, возврат на обзор
├─ Переключатель пространства → выбор / создание / настройки команды
├─ Обзор              → /
├─ Стата              → /stats
├─ Таймшит            → /timesheet
├─ График             → /graph
├─ Цели               → /goals
├─ Теги               → /tags
├─ Проекты            → /projects
├─ CSV                → /api/reports.csv  (скачать экспорт)
├─ Ещё ▾              → Инвойсы · Фонд оплаты · Отчёты · Импорт · Расписание
├─ RU ▾               → смена языка
├─ ◐ auto             → тема (T)
└─ Имя ▾              → Команда · Профиль · API-токены · Справка · Интеграции · Выход
```

Всего **8 прямых пунктов** + два выпадающих меню. Денежные и экосистемные
функции не перегружают основную навигацию — они в «Ещё».

**`/help` — Справка** описывает все возможности в одном месте: учёт, разбор,
проекты, деньги, команда, экосистема, горячие клавиши и «где что находится».
Ссылка — в меню профиля.

## 1. Первый визит и регистрация

```
/  (аноним → 303)
 └→ /login
     ├→ /register ──→ POST /api/register ──→ /  (личное пространство создано)
     ├→ /sso/login  (если настроен OIDC)
     ├→ /forgot-password → /reset-password
     └→ /lang/ru | /lang/en   (переключатель виден и на публичных страницах)
```

**Что помогает:** язык переключается до входа; пароль-восстановление
доступно с экрана логина; после регистрации пользователь сразу на обзоре с
формой «Новая активность».

**Онбординг при первом входе** — живой чек-лист из трёх шагов прямо на
обзоре (не модалка, не тур):

| Шаг | Что делает | Как отмечается |
|---|---|---|
| 1 · Запустите таймер | фокус на поле «Активность» | галочка после реального `POST /api/start` |
| 2 · Посмотрите, куда ушло время | переход на `/stats` | по клику |
| 3 · Добавьте проект | переход на `/projects/new` | по клику |

Карточка показывается **только пока у аккаунта нет ни одной сессии** и не
нажато «Скрыть». «Скрыть» пишет флаг в `localStorage` и не возвращается.
Аккаунты с историей онбординг не видят совсем. Ссылка на «Справку» — внизу
карточки.

## 2. Основной цикл: учёт времени

```
/  «Новая активность»
 │   Activity + Проект (необязательно) + Заметка
 └→ [Старт] ──→ активная сессия в «Активные сессии»
                  ├─ [Фокус]  — фокус на первой, остальные паузуются
                  ├─ [Пауза] / [Продолжить]
                  ├─ [Стоп]   — подтверждение, попадает в «Недавние сессии»
                  └─ длительность тикает вживую

/  «Добавить прошедшую сессию»
 └→ Backfill (в свободной форме: «вчера 14:00», «2h ago»)
```

**Обратный путь из любой точки:** `n` — новая сессия (работает глобально),
клик по логотипу — на обзор.

## 3. Правка и разбор

```
/stats
 ├─ Вкладки периода: Сегодня · Вчера · Неделя · Месяц · Всё время
 ├─ Фильтры: проект · тег  (сохраняются в URL)
 ├─ Разбивка по проектам и активностям
 ├─ Сохранённые отчёты — чипсы поверх фильтров
 └─ Лог сессий → инлайн-правка (начало / конец / длительность / заметка / теги)

/graph   → график по тем же фильтрам (ECharts, лениво)
/goals   → цель по активности (день / неделя / месяц)
/tags    → создание и управление тегами
```

**Что помогает:** цифры в моноширинном шрифте выровнены по колонкам;
правка на месте — без модалок; фильтры делятся ссылкой.

---

## 4. Неделя целиком

```
/timesheet  — сетка «активность × дни», ячейка = минуты за день
 ├─ правка ячейки сразу сохраняет день
 ├─ 0 очищает день
 └─ пустое состояние подсказывает: «Запустите таймер на обзоре»

/schedule   — план людей × проекты на неделю (загрузка % от ёмкости)
```

## 5. Проекты и деньги

```
/projects
 └→ /projects/{slug}
      ├─ Оценка (estimate) vs факт — карточка с прогрессом
      ├─ Ставка (cents/час) + чекбокс «оплачиваемый»
      ├─ Активности проекта
      └─ Правка / архивирование

/invoices
 ├─ Сформировать счёт: клиент + период + проект
 │    → BuildInvoiceLines (только оплачиваемые проекты)
 │    → INV-YYYY-NNN
 └→ /invoices/{id}
      ├─ [PDF]        — серверный рендер
      ├─ [Ссылка]     — ручная платёжная ссылка
      ├─ [Оплата]     — Stripe Checkout (если настроен)
      └─ [Отметить оплаченным]

/payroll
 ├─ Ставка и ёмкость задаются в Настройки → Участники
 └→ /payroll/{id}  — PAY-YYYY-NNN, печать, отметка «выплачено»
```

**Что помогает:** деньги в целых центах, формат `12.45`; «неоплачиваемый»
проект и время без проекта **не попадают** в счёт.

## 6. Отчёты и экспорт

```
/reports  — галерея шаблонов (5 штук), у каждого своя форма «с … по …»
 └→ /reports/run?id=&from=&to=
      ├─ HTML-таблица (для billable-шаблонов — ставка и сумма)
      └─ &format=csv  → key,hours,seconds,rate_cents,amount_cents,share

CSV из шапки  → /api/reports.csv  (быстрый экспорт текущих фильтров)
```

## 7. Команда

```
Настройки → Рабочее пространство
 ├─ переименование
 ├─ создание нового пространства
 ├─ Stripe-ключи (онлайн-оплата)
 └─ опасная зона: удаление

Настройки → Участники
 ├─ оплата (cents/ч) и ёмкость (мин/день) по каждому
 └─ удаление участника

Настройки → Приглашения
 └→ ссылка-приглашение → /invites/{token} → принять → вход/регистрация

Переключатель пространства в шапке — быстрый переход
```

## 8. Экосистема

```
Настройки → API-токены     — pt_… для расширения / CLI / скриптов
Настройки → Интеграции     — подключённые провайдеры
/integrations/marketplace   — витрина из 11 карточек (8 рабочих + «скоро»)
/integrations/{id}          — секрет, цель, импорт задач → однокликовый старт
/import                     — Toggl / Harvest / Clockify
Настройки → Webhooks        — HMAC-подпись, журнал доставок
Настройки → Аудит           — последние 100 событий
Настройки → Уведомления     — web push (VAPID)
```

**API v1** (Bearer `pt_…` или сессия):
`GET|POST /api/v1/sessions`, `PATCH|DELETE /api/v1/sessions/{id}`,
`GET /api/v1/projects`, `GET /api/v1/reports/summary`.


## Ясность UI: что подтверждено и что доделали

**Подтверждено:**
- Основной цикл (учёт → разбор → неделя) — **3 клика** от старта до любого места
- Каждая из 8 областей достижима из верхней панели или из «Ещё» / меню профиля
- Пустые состояния есть на обзоре, стате, инвойсах, целях, тегах
- Горячие клавиши (`n` `s` `g` `t`) подписаны в подвале
- Один `h1` на страницу, кнопки в единой лестнице 40/32/24px
- Русский по умолчанию, переключатель на всех страницах

**Доделано в этом проходе:**
- Пустые состояния на `/timesheet`, `/payroll`, `/reports/run`
- Обрезка слов в таблицах (`Dem/o`) и бейджей ролей (`дел`) на планшетах
- `/settings/members` — таблица скроллится, страница не растягивается
- **`CSV` вынесен в основную панель** (был в «Ещё»)
- **`/help` — Справка** со всеми возможностями и «где что находится»
- **Онбординг при первом входе** — чек-лист из 3 шагов, живёт только пока
  аккаунт новый

**Известные слабые места (не блокируют):**
- `/settings/tokens` и `/integrations` видны только через меню профиля
- Шаблоны отчётов и маркетплейс — статические карточки, без превью данных
