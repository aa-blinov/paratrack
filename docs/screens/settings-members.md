# Участники — `/settings/members`

Список состава пространства: роль, почасовой оплата и ёмкость по дням — всё
в одной карточке, без прокрутки.

## Смысл экрана

Экран отвечает на два вопроса сразу: «кто в команде и с какими правами» и
«сколько платить каждому». Сверху — заголовок «Участники» и одна кнопка
«Приглашения» справа (`y=86–114`), под ней полоса из 11 вкладок настроек
(`y=130–168`), где активна «Участники» (`x=823`).

Дальше карточка «Участники (N)»: каждая строка — это участник, и в строке
сразу три вещи. Слева имя и почта, в середине роль, справа два поля ввода
«Оплата в час» и «Ёмкость (мин/день)» и кнопка «Сохранить». У своей строки
вместо роли — серый бейдж «владелец», а вместо кнопки «Убрать» — подпись
«это вы».

На измеренном инстансе (владелец + один приглашённый участник) обе строки
помещаются в первый экран: карточка участников занимает `y=221–471`, своя
строка — `y=267–353`, чужая — `y=361–455`. Прокрутка не нужна ни для одной
из правок. Вся страница — 900px, `scrollHeight=900`.

Под списком, когда участников больше одного, появляется карточка «Передать
владение» (`y=487–637`) с одним селектом «Кому» и красной кнопкой «Передать».
Она тоже в первом экране.

Правка роли и ставки уходит через обычную форму с сабмитом, страница
перезагружается целиком, `scrollY=0`, сверху появляется строка
`role=status` «Схранено.» на `y=221`. Ни тоста, ни подсветки изменённой
строки, ни пометки «какая именно кнопка сработала» — при трёх участниках
понять, чью ставку поменяли, можно только памятью.

## Что проверить вручную

- Взгляд администратора (не владельца) на этот же экран: в браузере не
  воспроизведён — участника удалили до конца проверки. По коду
  (`team-members-page.tsx:23–24`) у него роль становится обычным текстом,
  ставка владельца — read-only, карточка передачи владения не рендерится вовсе.
  Надо руками: остаётся ли хоть какая-то правка у администратора и понимает
  ли он, почему роль не меняется.
- Список из 10–20 участников: страница перестаёт помещаться в 900px, все ли
  строки видны без прокрутки и остаётся ли «Передать владение» внизу.
- Мобильная раскладка: строка из четырёх колонок перестраивается в стек —
  где оказываются поля ставки и не уезжают ли подписи.
- Приглашение, по которому человек вступил дважды: один токен — один
  участник, но что покажет второй, вошедший по старой ссылке.
