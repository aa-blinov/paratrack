# CRM — `/crm`

Сделки команды, контакты клиентов и лиды. Список сделок сгруппирован по
стадиям воронки; плитки-фильтры по стадиям («Все», «Новая», «В работе»,
«Предложение», «Выиграна», «Проиграна») стоят над списком, каждая показывает
и число сделок. Плитка «Просрочены» отвечает за сделки, у которых прошёл
следующий шаг.

## Клики до действий

Замерено в браузере на стенде `scripts/qa-env.sh up`, 1440×900:

| Действие | Кликов | Путь |
|---|---|---|
| Найти клиента или контакт | 1 | «Поиск клиентов и контактов» → минимум два символа (`crm.search.title`) |
| Переключить вкладку «Сделки / Лиды / Воронка» | 1 | кнопки над списком |
| Создать сделку от существующего клиента | 4 | «Новая сделка» (раскрыть) → «Название сделки» → «Клиент» → «Создать сделку» |
| Записать звонок/встречу в историю | 4 | «История» → «Тип записи» → «Что обсудили» → «Записать» |
| Перевести сделку на другую стадию | 4 | карточка сделки → «Стадия» → новая стадия → «Перевести» |

## Поля сделки

Форма `deal-form.tsx`:

| Поле | Куда идёт | Примечание |
|---|---|---|
| Название | заголовок сделки в списке | обязательно |
| Клиент | из справочника `/clients` | без клиента сделка не создаётся |
| Сумма | `amount_cents`, показывается в списке | валюта — командная |
| Вероятность, % | `probability` | 0–100, влияично на воронку |
| Дата закрытия | `close_date` | нужна для плитки «Просрочены» |
| Следующий шаг | `next_step_at` | подсказка «Пора сделать следующий шаг» (`crm.next.*`) |

## Слабые места

| Что | Почему мешает | Как снимается |
|---|---|---|
| История и контакты клиента живут на отдельной карточке `/clients` | чтобы посмотреть звонки, нужно уйти со списка сделок; в списке нет даже числа записей | счётчик записей в строке сделки |
| Вероятность не связана со стадией | «Вероятность» задаётся руками, хотя стадия уже подразумевает диапазон | подставлять значение по стадии, как в `stage-editor.tsx` |

## Что проверить вручную

- Перевод сделки на стадию «Проиграна»: без причины провала поле подсвечивается.
- Поиск минимум с двумя символами: одна буква не ищет, ошибки нет.
- После создания сделки форма очищается, сделка появляется в своей стадии.
