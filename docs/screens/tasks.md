# Задачи — `/tasks`

Экран учёта работы исполнителей: таблица задач с проектом, статусом,
исполнителем и учётом времени. Три вкладки-вида: «Таблица», «Доска»,
«Архив» (`web/src/tasks/tasks-page.tsx:126-130`). Живую разметку рендерит
React (`web/src/main.tsx` → `#paratrack-react-root`), данные приходят из
`internal/web/handlers_*`.

## Смысл экрана

Задачи — единственный крупный раздел без привязки к деньгам: время здесь
считается вручную (оценка и учтённые минуты), ставки проектов на экране не
видны. Таблица отвечает на вопрос «что кому поручено и что уже сделано»:
колонки «Задачи», «Проект», «Статус», «Исполнитель», «Учтено», «Срок» и
действия строки.

Смена статуса — селект Radix прямо в строке таблицы: два клика (открыть
раскрывающийся список, выбрать пункт), без подтверждения и перезагрузки.
Статусы фиксированы: «К работе», «В работе», «Готово».

Форма «Новая задача» открыта над списком постоянно, сворачивать её нельзя.
Поля: название (обязательно), проект, исполнитель, срок (свободная дата —
принимает и «30.10.2026», и «31.02.2026» с ошибкой «не распознан»), оценка
времени, описание. После отправки приложение уводит с списка на карточку
задачи `/tasks/{id}` — чтобы завести следующую, нужно вернуться назад.

## Пользовательские истории

| Я | хочу | чтобы | экран |
|---|---|---|---|
| Руководитель студии | завести задачу одним входом и вернуться к списку | форма создания рядом со списком, без отдельной страницы | `/tasks` |
| Руководитель студии | назначить задачу участнику прямо из списка | селект исполнителя в строке, без карточки | `/tasks` |
| Исполнитель | увидеть свои задачи и сменить статус | строка → селект статуса → пункт | `/tasks` |
| Исполнитель | присвоить работе готовую задачу | таймер не связан с задачей: время на задаче учитывается в её активностях | `/tasks` |
| Руководитель студии | убрать закрытую задачу из списка, но не потерять её | архив с восстановлением в один клик | `/tasks?view=archive` |

## Клики до действий

Замерено на стенде `scripts/qa-env.sh up`, окно 1440×900, сайдбар раскрыт,
кириллическая локаль по умолчанию. Ввод текста кликами не считается.

| Действие | Кликов | Путь |
|---|---|---|
| Открыть экран | 1 | меню «Задачи» |
| Создать задачу | 1 | заполнить заголовок → «Новая задача» (форма открыта над списком) |
| Сменить статус из таблицы | 2 | селект «Статус: …» в строке → пункт |
| Открыть карточку задачи | 1 | название задачи в строке таблицы |
| Вернуться к списку из карточки | 1 | «Задачи» в сайдбаре |

## Слабые места

| Что | Почему мешает | Как снимается |
|---|---|---|
| После создания задачи открывается её карточка, а не список | завести несколько задач подряд — по лишнему «назад» на каждую; список — рабочий вид руководителя | возвращать на список или дать ссылку «создать ещё одну» рядом |
| Оценка времени в форме принимает «31.02.2026» и падает с ошибкой только при отправке | срок не проверяется до сабмита, часть формы уже набрана | валидировать дату при вводе, как это делает `DateField` в других формах |
| Нет массовых действий в таблице | переназначить исполнителя у трёх задач — шесть кликов по селектам | чекбоксы строк и групповое действие |

## Что проверить вручную

- Архив: вкладка «Архив» и восстановление задачи кнопкой «Вернуть» — в замер
  не входил, проверить на заполненном пространстве.
- Поведение при пустом списке проектов: форма требует проект, проверить
  подсказку.
- Импорт с GitHub Projects (кнопка внизу экрана) — отдельный сценарий.

## Источники

- `web/src/tasks/tasks-page.tsx:126-130` — вкладки видов; `:149-150` — кнопка
  «Новая задача» и форма создания; `:184` — кнопка отправки; `:195-196` —
  карточки на доске; `:225` — ссылка на задачу в строке таблицы; `:282` —

- `internal/i18n/dict/ru.json` — подписи `tasks.*` («Новая задача», «К

  и в карточке задачи.
