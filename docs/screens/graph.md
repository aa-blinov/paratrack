# По часам — `/graph`

Распределение учтённых минут по часам суток, разложенное по активностям:
единственный экран, который отвечает на вопрос «в какие часы я работаю».

## Смысл экрана

Человек приходит с одним вопросом про свой ритм: когда за день набирается
больше всего работы и совпадает ли это с часами, когда он на связи. Экран
даёт один столбчатый график — ось X это часы суток от «00» до «23», высота
столбца — минуты за весь выбранный период, цвет — активность. Подпись под
шапкой объясняет это прямо: «Высота столбца показывает, сколько минут в этот
час было учтено за весь период, цвет показывает активность. Нажмите на
активность ниже, чтобы скрыть или вернуть её».

Период задаётся шестью вкладками над графиком (Сегодня, Вчера, Эта неделя,
Прошлая неделя, Этот месяц, Прошлый месяц). По умолчанию открыт «Сегодня».
Единственная цифра под графиком — «Всего учтено: N», точные минуты лежат в
тултипе при наведении или тапе на столбец. Под графиком — легенда «Активности
(нажмите, чтобы скрыть или показать)», чипы работают как переключатели
(`aria-pressed`).

Фильтров на самой странице нет. Любой фильтр приезжает из `/stats` по адресу:
тогда появляется плашка «Показано только: …» с кнопкой «Сбросить фильтры».
В шапке есть ссылка «← Статистика», которая возвращает к разбивке с теми же
периодом и фильтрами. На самом экране нет ни экспорта, ни печати, ни полей
даты — это видно и по разметке, и по поведению.

## Пользовательские истории

| Я | хочу | чтобы | экран |
|---|---|---|---|
| Фрилансер | увидеть, в какие часы у меня больше всего работы | один график по всем дням периода | По часам |
| Сотрудник | спрятать активность, которая мешает читать график | один клик по чипу легенды | По часам |
| Руководитель | сравнить неделю с прошлой | смена периода в один клик с сохранением фильтров | По часам |
| Сотрудник | понять, что было в конкретный час | из столбца перейти к тем сессиям | По часам |
| Владелец студии | унести график в документ | печать или выгрузка прямо со страницы | По часам |
| Сотрудник | посмотреть график только по своему проекту | сузить выборку, не возвращаясь назад | По часам |

## Клики до действий

| Действие | Кликов | Путь | Горячие клавиши |
|---|---|---|---|
| Открыть «По часам» | 1 | 1 (меню → По часам); из статистики — тоже 2 от обзора (1 + «Посмотреть по часам») | — |
| Сменить период на «Эта неделя» | 2 | 1 (меню) + 1 (вкладка периода) | — |
| Посмотреть конкретный день | 2 | 1 (меню) + 1 («Сегодня» или «Вчера») | — |
| Посмотреть прошлую неделю | 2 | 1 (меню) + 1 («Прошлая неделя») | — |
| Посмотреть произвольную дату, например вторник месячной давности | нет в UI | только вручную в адресе `?period=…`: стрелок недель нет, полей даты на странице нет | — |
| Скрыть активность в легенде | 3 | 1 (меню) + 2 (клик по чипу легенды) | — |
| Отфильтровать по проекту | 3 | 1 (меню) + 1 (чипс проекта в статистике) + 1 («Посмотреть по часам с этими фильтрами») | — |
| Отфильтровать по тегу | нет в UI | тег ставится только руками в адресе; ссылка «по часам» сохраняет уже стоящий | — |
| Отфильтровать по человеку | 3 | 1 (меню → Статистика) + 1 (селект «Человек») + 1 («Посмотреть по часам с этими фильтрами») | — |
| Сбросить фильтры | 4 | 1 (меню) + 2 (поставить фильтр) + 1 («Сбросить фильтры») | — |
| Вернуться к цифрам в статистике | 2 | 1 (меню) + 1 (ссылка «← Статистика» в шапке) | — |
| Выгрузить данные в CSV | 1 | 1 (меню → Экспорт, `/export`); на `/graph` кнопок нет | Ctrl+P — меню браузера, не кнопка |
| Распечатать график | нет в UI | печать браузера; на `/reports` для того же есть отдельные кнопки | Ctrl+P |

## Слабые места

| Что | Почему мешает | Как снимается |
|---|---|---|
| Экспорта и печати со страницы нет вообще | Внутри `main` не нашлось ни одного контрола про печать, CSV или выгрузку. Унести график можно только через `/export` (1 клик из меню), а там выгрузка идёт по сессиям, а не по часам: ради единственной диаграммы радикала нужно идти на другой экран и собирать срез заново | «Скачать PNG» и «Скачать CSV по часам» под графиком, плюс печать |
| Клик по столбцу ничего не открывает | По клику на столбец появляется тултип («04:00», «0 мин»), но адрес не меняется и перехода нет (`graph-02-week.png`). Из «когда я работаю» нельзя перейти к тем сессиям — остаётся ссылка «← Статистика» в шапке и поиск заново | Раскрывать столбец в сессии этого часа или в срез по дням |
| Выбрать дату нельзя | Только 6 вкладок периода. Стрелок «неделя вперёд/назад», как на `/timesheet` и `/schedule`, нет, полей даты тоже нет: в `main` не нашлось ни одного `input`. Вопрос «как я работал в тот вторник» решается только адресной строкой | Тот же недельный навигатор, что на табеле, или выбор даты |
| Фильтров на странице нет ни одного, а приезжают они откуда-то | Любой фильтр можно поставить только в `/stats`; здесь есть только плашка «Показано только: …» и «Сбросить фильтры». Человек, пришедший за «своим графиком по проекту», обязан уйти назад и вернуться | Проекты, теги и люди теми же чипсами, что в статистике, или явная ссылка «настроить фильтры» |
| «Сбросить фильтры» на экране появляется дважды | При фильтре без данных (`/graph?period=week&tag=глубокая-работа`) кнопка есть и в плашке «Показано только:», и в пустом состоянии «Пока нет данных. За этот период по выбранным фильтрам сеансов нет.» (`graph-04-filtered-empty.png`) | Одна кнопка, вторую убрать |
| Выбор легенды не попадает в адрес | Клик по чипу переключает серию (`aria-pressed` true → false → true), но URL остаётся прежним — поделиться ссылкой на «график без двух активностей» нельзя, и после перезагрузки всё возвращается | Складывать набор видимых серий в параметр адреса |
| Единственная цифра — «Всего учтено», значения столбцов только в тултипе | Под графиком нет ни подписей, ни таблицы значений: чтобы назвать конкретный час и минуты, нужно навести курсор, а с телефона — тапнуть и попасть в мелкий тултип | Числовые подписи у столбцов или короткая сводка «пик: 11:00 — 2 ч 30 мин» |

## Что проверить вручную

- Тултип на телефоне: тап по столбцу показывает значение, но размер и
  положение подписи на 360px не проверены.
- Доступность графика с клавиатуры: легенда — настоящие кнопки, а контейнер
  `#echart-canvas` помечен `role="img"` (`graph-page.tsx:71`), то есть столбцы
  с клавиатуры не читаются; нужен скринридер.
- Печать страницы браузером: на `/reports` печать отлажена, на `/graph` не
  проверено — печатный лист и пустая страница выглядят по-разному.
- Сведение итогов: «Всего учтено: N» на `/graph` против «Итого» в
  `/stats` за тот же период и те же фильтры — вручную не сверялось.
- Легенда при длинном списке активностей: на измеренном инстансе 4 чипа, как
  себя ведёт список из 20–30 чипов и не разъезжается ли сетка.
