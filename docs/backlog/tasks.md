# Задачи

Источник: регламент учёта времени, QA-проход 20.10.2026 (роли «сотрудник», «руководитель», «администратор»). Задача сейчас: название, статус из трёх колонок, исполнитель, срок, оценка, активности. Описания, комментариев, подзадач и наблюдателей нет.

## P1

- [ ] **TASK-01** (P1, M). Описание задачи: поле в форме и редактирование на странице задачи. Регламент требует конкретную постановку: «нет задачи, нет работы». Источник: сотрудник, кейс 1; руководитель, кейс 8; администратор.
- [ ] **TASK-02** (P1, M). Комментарии к задаче: лента с автором и датой. При остановке таймера можно добавить результат одной строкой. Регламент: «добавить комментарий с кратким описанием результата». Источник: сотрудник, кейс 1.
- [ ] **TASK-03** (P1, M). Переназначение задачи переносит часы по дням или предлагает перенос. Сейчас план у второго исполнителя не меняется: у одного осталось 40 часов плана при перегрузке. Источник: руководитель, кейс 8.
- [ ] **TASK-04** (P1, M). Отчёт по задачам, аналог «Отчёта времени по задачам. Расширенное» из регламента: строка на задачу, колонки исполнитель, проект, статус, оценка, учтено, срок; фильтр по периоду; выгрузка CSV. Регламент использует его для еженедельного контроля. Источник: руководитель, кейс 9.
- [ ] **TASK-05** (P1, S). Срок задачи и напоминание о сроке в приложении и на почту, с отметкой просрочки. Сейчас системные уведомления не касаются сроков задач. Источник: менеджер по продажам, кейс 5; сотрудник.
- [x] **TASK-06** (P1, S). Задача с отключённым или удалённым исполнителем: предупреждение в таблице, а не пустое «Не назначен». Источник: администратор, кейс 3. Закрыто 2026-10-21: задача с исполнителем вне команды показывает «Исполнитель вне команды» выделенным цветом, в таблице и в мобильной карточке. Ссылка на исполнителя сохраняется.
- [ ] **TASK-07** (P1, S). Оценка задачи с единицами измерения: часы или минуты. Сейчас число без единиц. Источник: сотрудник, «Прочее».
