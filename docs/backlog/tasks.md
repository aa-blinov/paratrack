# Задачи

Источник: регламент учёта времени, QA-проход 20.10.2026 (роли «сотрудник», «руководитель», «администратор»). Задача сейчас: название, статус из трёх колонок, исполнитель, срок, оценка, активности. Описания, комментариев, подзадач и наблюдателей нет.

## P1

- [x] **TASK-01** (P1, M). Описание задачи: поле в форме и редактирование на странице задачи. Регламент требует конкретную постановку: «нет задачи, нет работы». Источник: сотрудник, кейс 1; руководитель, кейс 8; администратор. Закрыто 2026-10-22: описание задачи задаётся в форме создания и меняется на странице задачи; хранится в задаче, попадает в экспорт и восстановление.
- [x] **TASK-02** (P1, M). Комментарии к задаче: лента с автором и датой. При остановке таймера можно добавить результат одной строкой. Регламент: «добавить комментарий с кратким описанием результата». Источник: сотрудник, кейс 1. Закрыто 2026-10-22: лента на странице задачи с автором и датой; остановка таймера на активности задачи показывает под «Отменить» поле «Результат одной строкой», и строка уходит в ленту задачи. При остановке всех таймеров сразу поля нет.
- [x] **TASK-03** (P1, M). Переназначение задачи переносит часы по дням или предлагает перенос. Сейчас план у второго исполнителя не меняется: у одного осталось 40 часов плана при перегрузке. Источник: руководитель, кейс 8. Закрыто 2026-10-22: при переназначении, если у прежнего исполнителя есть план на проекте задачи с сегодняшнего дня, система спрашивает, перенести ли его новому исполнителю по дням. Переносится план проекта, а не план задачи: в продукте план хранится по человеку, проекту и дню, отдельного плана задачи нет. Переносит руководитель или ведущий проекта; для прочих перенос отказывает с причиной.
- [x] **TASK-04** (P1, M). Отчёт по задачам, аналог «Отчёта времени по задачам. Расширенное» из регламента: строка на задачу, колонки исполнитель, проект, статус, оценка, учтено, срок; фильтр по периоду; выгрузка CSV. Регламент использует его для еженедельного контроля. Источник: руководитель, кейс 9. Закрыто 2026-10-22: вкладка «Отчёт» на странице задач, только для руководителя. Строка на задачу с учтённым временем в периоде (день включительно, открытые таймеры до текущего момента, архивные задачи остаются); задачи без времени в периоде строки не получают. Выгрузка `/api/tasks/report.csv` с тем же периодом.
- [x] **TASK-05** (P1, S). Срок задачи и напоминание о сроке в приложении и на почту, с отметкой просрочки. Сейчас системные уведомления не касаются сроков задач. Источник: менеджер по продажам, кейс 5; сотрудник. Закрыто 2026-10-22: исполнитель получает напоминание в день срока или накануне, и ещё одно, когда задача просрочена, по push и по почте, если настроен SMTP. Тема «Срок задачи» выключается в настройках. Не больше двух напоминаний на срок: до срока и при просрочке.
- [x] **TASK-06** (P1, S). Задача с отключённым или удалённым исполнителем: предупреждение в таблице, а не пустое «Не назначен». Источник: администратор, кейс 3. Закрыто 2026-10-21: задача с исполнителем вне команды показывает «Исполнитель вне команды» выделенным цветом, в таблице и в мобильной карточке. Ссылка на исполнителя сохраняется.
- [x] **TASK-07** (P1, S). Оценка задачи с единицами измерения: часы или минуты. Сейчас число без единиц. Источник: сотрудник, «Прочее». Решение 2026-10-21: оценка хранится в минутах и вводится в формате 1:30, как длительность сессии (TIME-09). Основание: один формат длительности во всём продукте. Закрыто 2026-10-21: оценка вводится и показывается как 1:30, хранится в минутах. Нечитаемое значение отклоняется вместо молчаливого нуля. Простые минуты тоже принимаются.
- [x] **TASK-15** (P1, S). Задача с заголовком, которое уже есть у активности команды, не создаётся: ответ 500, потому что имя активности уникально в команде (`activities_team_name_key`). Найдено 2026-10-22 при проверке почты. Решение нужно: переиспользовать активность с тем же именем, или дать задаче свою активность с другим именем. Выбор влияет на то, куда уходит время задачи, поэтому решает владелец продукта. Закрыто 2026-10-22: задача с названием, которое уже есть у свободной активности того же проекта, забирает эту активность, её время и сессии остаются на месте. Если активность занята другой задачей, стоит в другом проекте или в архиве, создание отказывает с причиной «переименуйте задачу», а не ошибкой сервера.
