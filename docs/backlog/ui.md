# Интерфейс: поиск, отказы, подписи

Источник: QA-проход 20.10.2026, все роли. Пункты, которые касаются конкретной предметной области, записаны в соответствующих документах, здесь только общее и интерфейсное.

## P1

- [ ] **UI-01** (P1, M). Глобальный поиск. Сейчас Ctrl+K открывает только выбор, а поиска по клиентам, проектам, задачам и сессиям нет. Искать по названию, почте и тегам. Источник: менеджер по продажам, кейс 7. Связано: [crm.md](crm.md), CRM-11; [tasks.md](tasks.md), TASK-14.
- [ ] **UI-02** (P1, S). Общий отказ «Что-то пошло не так у нас» встречается при правке утверждённой недели, при добавлении сессии задним числом в закрытую неделю и при создании ссылки на оплату. Каждый отказ называет причину и, если можно, следующий шаг. Источник: руководитель, кейс 7; сотрудник, кейс 9; бухгалтер, кейсы 2 и 9. Связано: [time.md](time.md), TIME-03; [finance.md](finance.md), FIN-14.
