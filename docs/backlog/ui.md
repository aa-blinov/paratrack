# Интерфейс: поиск, отказы, подписи

Источник: QA-проход 20.10.2026, все роли. Пункты, которые касаются конкретной предметной области, записаны в соответствующих документах, здесь только общее и интерфейсное.

## P1

- [x] **UI-01** (P1, M). Глобальный поиск. Сейчас Ctrl+K открывает только выбор, а поиска по клиентам, проектам, задачам и сессиям нет. Искать по названию, почте и тегам. Источник: менеджер по продажам, кейс 7. Связано: [crm.md](crm.md), CRM-11; [tasks.md](tasks.md), TASK-14. Закрыто 2026-10-22: Ctrl+K или / открывает поиск по клиентам, проектам, задачам, тегам, людям (руководителю, по имени и почте) и своим сессиям; ответ ссылками, почта клиента только руководителю. В коде не нашлось выбора, который Ctrl+K открывал раньше: сочетание добавлено вместе с поиском.
- [x] **UI-02** (P1, S). Общий отказ «Что-то пошло не так у нас» встречается при правке утверждённой недели, при добавлении сессии задним числом в закрытую неделю и при создании ссылки на оплату. Каждый отказ называет причину и, если можно, следующий шаг. Источник: руководитель, кейс 7; сотрудник, кейс 9; бухгалтер, кейсы 2 и 9. Связано: [time.md](time.md), TIME-03; [finance.md](finance.md), FIN-14. Закрыто 2026-10-22: три сценария называют причину: правка в утверждённой неделе, ручной ввод и backfill в закрытую неделю (с названием недели), ссылка на оплату (причина из ключа Stripe, FIN-14). Общий текст остаётся только для непредвиденных ошибок сервера.

## P2

- [x] **UI-03** (P2, S). Блок «Счета» на карточке клиента виден, даже когда раздел «Счета» выключен. Скрывать вместе с разделом. Источник: менеджер по продажам, кейс 6. Закрыто 2026-10-22: блок счетов на карточке клиента скрыт, когда раздел «Счета» выключен.
- [x] **UI-04** (P2, S). Подписи «Сумма» и «Выставлено» на карточке клиента неочевидны. Уточнить, сумма чего и за какой период. Источник: менеджер по продажам, кейс 6. Закрыто 2026-10-22: подписи уточнены: «Выставлено счетами», «Всего по счетам» и подпись «За всё время, по всем проектам клиента».
- [x] **UI-05** (P2, S). Кнопка «Удалить сессию» в утверждённой неделе пропадает без пояснения. Показывать её недоступной с причиной. Источник: сотрудник, кейс 9. Закрыто 2026-10-22: в утверждённой неделе кнопка удаления сессии недоступна, рядом написано, какая неделя закрыта и кто может снять утверждение.

Закрыто 2026-10-22: участник, открыв выключенный раздел, видит предупреждение «попросите владельца или администратора включить его». Прежний текст отсылал к «Разделам», которые участник открыть не может.
- [x] **UI-07** (P2, S). После удаления счёта на экране появляется «Участник удалён.»: общий флаг, сообщение неверное. Исправить флаг. Источник: администратор, раздел «Прочее». Закрыто 2026-10-22: после удаления счёта показывается «Счёт удалён.», у флага собственный код, а не общий «Участник удалён».
